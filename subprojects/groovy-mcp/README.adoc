= Groovy MCP Module

`groovymcp` speaks the Model Context Protocol over stdio so an agent
can ask the Apache Groovy compiler about source.

The server does not run scripts, does not enable `@Grab` or `@ASTTest`,
and does not scan a workspace. Semantic answers come from
`GroovyLanguageEngine` in the `groovy-lsp` module.

See link:src/spec/doc/mcp-userguide.adoc[mcp-userguide.adoc] for the user guide
and link:ARCHITECTURE.md[ARCHITECTURE.md] for the contributor map.
