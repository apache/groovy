= Groovy Language Server Module

Implements the Language Server Protocol for Apache Groovy.
Editors and AI tools (and a later groovy-mcp wrapper) share this
language core; it is not a full IDE.

See link:src/spec/doc/groovy-lsp.adoc[groovy-lsp.adoc] for usage
and link:ARCHITECTURE.md[ARCHITECTURE.md] for the contributor map.
